# 🏋️ FusionFit – Premium Gym Website

A modern, fully responsive gym landing page built with **React (Vite)**, **Tailwind CSS v4**, and **Framer Motion**.  
Designed to deliver a premium fitness experience with smooth animations, dark aesthetic, and production-ready code.

## ✨ Features

- ✅ **Fully Responsive** – Mobile, tablet, and desktop optimized  
- ✅ **Smooth Animations** – Framer Motion for entrance, hover, and scroll effects  
- ✅ **Dark Modern UI** – Black background with neon green/electric blue accents  
- ✅ **Sticky Navbar** – With animated mobile hamburger menu  
- ✅ **Hero Section** – Fullscreen with CTA buttons and background image  
- ✅ **Programs Section** – Four training cards with icons and hover animations  
- ✅ **Trainers Section** – Cards with image overlay and scale effect  
- ✅ **Pricing Plans** – Three tiers with recommended badge  
- ✅ **Testimonials** – Client reviews with star ratings  
- ✅ **Contact Form** – Styled inputs, ready for API integration (Axios included)  
- ✅ **Footer** – Social links, quick links, and copyright  
- ✅ **Back-to-Top Button** – Smooth scroll helper  
- ✅ **Loading Animation** – Spinner while content loads  
- ✅ **Clean Folder Structure** – Maintainable and scalable

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/fusionfit-gym.git
   cd fusionfit-gym```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn
   ```

3. **Start development server**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

   Open 👉 [http://localhost:5173](http://localhost:5173) to view it.

   **Build for production**
   ```bash
   npm run build
   # or
   yarn build
   ```


# 🎨 Design Highlights
- ### Color Palette

  - Primary: Black (#000000) and dark grays

  - Accent: Neon green (#a3e635) and electric blue gradients

- ### Typography

  - Headings: Poppins (bold, modern)

  - Body: Inter (clean, readable)

- ### UI Patterns

  - Glassmorphism on cards and navbar

  - Smooth hover scaling and border glows

  - Gradient text for brand name
